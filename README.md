# ❄️ Winter Gallery

A fully responsive photography gallery website inspired by the [Tooplate 2151 Winter Gallery](https://www.tooplate.com/live/2151_winter_gallery) template.

## 📁 Project Structure

```
winter_gallery/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles + media queries
├── js/
│   └── main.js         # Navigation, gallery filter, scroll effects
└── README.md
```

## 📱 Responsive Breakpoints

| Screen | Breakpoint | Layout |
|--------|-----------|--------|
| Laptop/Desktop | 1200px+ | 3-column gallery, side-by-side sections |
| Tablet | 768px – 1199px | 2-column gallery, adapted grids |
| Mobile | Below 768px | Single column, hamburger menu |

## ✅ Features

- Sticky navbar with scroll effect + hamburger menu for mobile
- Full-screen hero section with background image
- About section with image + statistics
- Filterable masonry-style photo gallery
- Portfolio / featured work section
- Client testimonials
- Contact form with success message
- Newsletter signup in footer
- Scroll reveal animations
- CSS custom properties for easy theming

## 🚀 Deployment

### Deploy to Netlify (Drag & Drop)
1. Go to [app.netlify.com](https://app.netlify.com)
2. Drag the **`winter_gallery`** folder into the deploy area
3. Your site is live instantly!

### Deploy to Vercel
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → New Project → Import repo
3. No build settings needed — just deploy

### Deploy to GitHub Pages
1. Create a repo on GitHub
2. Upload all files
3. Settings → Pages → Source: main branch / root
4. Your site is at `https://yourusername.github.io/repo-name`
